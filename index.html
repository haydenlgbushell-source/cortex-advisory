Case Study

MB Auto Collective:
From manual to
automated.

A boutique used car dealership spending 3–4 hours per listing on photography processing, ad writing, and social media publishing. Every car listed manually, every platform updated by hand.

Client
MB Auto Collective
Sector
Automotive Retail
Engagement
Quick Win
Outcome
5 min per listing

The Problem — Before

Before
  • 3–4 hours to list a single car
  • Photos processed one by one in separate apps
  • Ad copy written from scratch every time
  • Each platform — Carsales, Facebook, Instagram — updated manually
  • Inconsistent descriptions across listings
  • The client handling all of it personally, every time
After
  • Under 5 minutes from photos to published
  • Batch photo processing with automatic background removal
  • AI-generated copy from a single prompt
  • One trigger publishes to all platforms simultaneously
  • Consistent, on-brand descriptions every time
  • The client has 15+ hours back every week
"The old process wasn't just slow — it was a ceiling on how many cars we could move. Now that ceiling is gone."

The New Workflow — Step by Step

01

Photograph

Standard shoot on phone. Photos dropped into a shared folder. Nothing else required from the client.

02

Process

Automation detects new photos, removes backgrounds, applies consistent branding overlay, exports platform-ready sizes.

03

Write

AI generates the listing copy — headline, description, key features — in the dealership's voice from vehicle details.

04

Publish

One confirmation sends to Carsales, Facebook Marketplace, Instagram, and the website. Done.

Tools Built — Tech Stack

Photo Pipeline

Zapier + Remove.bg + Canva API. Auto-processes every photo dropped in the folder — no manual steps.

Copy Engine

GPT-4 prompt trained on existing listings. Outputs on-brand descriptions that need zero editing.

Publishing Hub

Central dashboard pushes to all platforms simultaneously. Single source of truth for all active listings.

Challenges Overcome

Challenge
  • Inconsistent photo quality and angles
  • Platform API limitations (Facebook, Carsales)
  • AI copy sounding generic or off-brand
  • Client resistant to changing a familiar process
Solution
  • Shot guide created — 8 angles, takes 6 minutes total
  • Hybrid approach: API where available, browser automation where not
  • Prompt engineering using 40+ real listings as training examples
  • Parallel run for 2 weeks — client saw the time saved first-hand

Results — 8 Weeks Post-Launch

Time per listing ↓ 94% (3.5hrs → 5min)
Listing consistency ↑ 100% on-brand
Weekly hours recovered 15+ hrs/week
Platform coverage per listing 4 platforms simultaneously
The Bottom Line

MB Auto Collective went from a process that physically couldn't scale — the client doing everything manually — to a system that runs itself. The client's time moved from production work to sales and customer relationships. The build took three weeks. The ROI was visible in the first week of use.
